# D & S Wedding Invitation — GitHub Pages

This is an original, bride-first wedding invitation inspired by the interaction pattern of the reference invitation.

## Main files

- `index.html` — page structure
- `style.css` — colors, layout, animations and responsive design
- `script.js` — **EDIT THIS FILE** for names, verse, date, time, venue and map link
- `images/` — put your future photos here

## GitHub Pages

1. Create a repository such as `invitation`.
2. Upload all files and the `images` folder.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**, branch `main`, folder `/ (root)`.
5. Save and open the GitHub Pages URL.

The invitation needs no server or database.


## IMPORTANT — GitHub Pages upload
Upload **index.html, style.css, script.js, and README.md directly into the root of your GitHub repository**.
Do NOT upload the `wedding_invitation_v2` folder itself as the only folder.

If the site ever appears stuck on “Tap to Open”, check that `script.js` is in the same folder as `index.html`.
After replacing files on GitHub Pages, wait a minute and hard-refresh the page (Ctrl+F5).
